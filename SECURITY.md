# Security and privacy

Report security or privacy issues privately through [GitHub private vulnerability reporting](https://github.com/freepeace13/fitmark/security/advisories/new). Do not open a public issue.

Include real candidate or client data in a report only if there is no other way to show the problem. Redact it wherever you can.

Examples of what to report:

- Contact details or `recruiter_only` content appearing in a client-facing output.
- A way to make a skill infer or output protected attributes.
- A profile or input file that makes a skill bypass the core rules.
- Real personal data in `fixtures/`.
